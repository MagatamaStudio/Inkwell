# 文本格式说明

Inkwell 认的输入只有"纯文本"，但有些约定会影响最终排版。这份文档说清楚：放哪里、什么编码、怎么控制分页、Markdown 会被怎么处理、一页到底能装多少。

---

## 1. 文件放哪

```
.minecraft/
└── inkwell/                ← 默认目录（配置项 folder 可改）
    ├── 第一章.md
    ├── 第二章.md
    ├── 番外.txt
    └── book.txt            ← Ctrl+Alt+V 专用，默认文件名（配置项 file 可改）
```

- 目录第一次导入时自动创建
- 文件按名字排序显示，可以用搜索框过滤
- 子目录不会递归扫描（只读这一层）

## 2. 支持的扩展名与编码

| 项 | 说明 |
|---|---|
| 扩展名 | `.txt` / `.md` / `.markdown`（大小写不敏感） |
| 编码 | **UTF-8**（带不带 BOM 都行，BOM 会自动去掉） |
| 换行 | `LF`、`CRLF`、`CR` 都可以，内部统一成 `\n` |
| 单文件上限 | 8 MB（配置项 `maxFileBytes`） |

> **GBK 编码的文件会乱码**。用记事本 / VS Code 另存为 UTF-8 即可。
> VS Code 右下角点编码 → "Save with Encoding" → UTF-8。

## 3. 分页控制

### 3.1 自动分页

默认按**阅读界面的实际排版**切页（`displayPaging=true`）：

- 文本区宽 **114 px**，每行由游戏字体实际折行
- 文本区高 128 px，行高 9 px → **每页 14 行**
- 行数满了就翻页，不会出现"点开只有半页字"

### 3.2 手动翻页：`---`

**单独一行的三个减号**（前后不能有其他字符）强制翻页：

```text
第一页的内容

---

第二页的内容
```

在 Markdown 里 `---` 本来是水平分割线，Inkwell 把它当成翻页标记——写小说时正好可以拿它控制章节开新页。

翻页标记本身不会被写进书里。配置项 `pageBreakLine` 可以改成别的，比如 `===`。

### 3.3 一页能放多少字

| 语言 | 一行约 | 一页（14 行）约 |
|---|---|---|
| 中文 | 12 字 | **170 字** |
| 英文 | 19 字符 | 270 字符 |

这是**阅读界面的显示上限**，不是 Inkwell 的限制。编辑框虽然能存 1024 字，但书里只会画出前 14 行——Inkwell 就是为了不让你踩这个坑才按显示宽度分页的。

> 想每页少放一点（比如留白多一点），把 `linesPerPage` 调成 12 或 10。

## 4. Markdown 处理

`.md` / `.markdown` 会先转成纯文本再分页（`markdown=false` 可关闭）。

| 原始写法 | 转换后 |
|---|---|
| `# 第一章` `## 第二节` | 第一章 / 第二节（井号去掉） |
| `**粗体**` `__粗体__` | 粗体 |
| `*斜体*` `_斜体_` | 斜体 |
| `~~删除~~` | 删除 |
| `` `行内代码` `` | 行内代码 |
| `[链接](https://…)` | 链接 |
| `![图](a.png)` | [图片] |
| `- 条目` `* 条目` `+ 条目` | · 条目 |
| `> 引用` | 引用（符号去掉） |
| 代码块 ```` ```java … ``` ```` | 只保留里面的内容，围栏行删掉 |
| 表格 `\| 名字 \| 数量 \|` | 名字 数量（竖线变空格） |
| 表格分隔行 `\| --- \| --- \|` | 整行丢弃 |
| `---`（单独一行） | **保留，作为翻页标记** |
| `<https://…>` | https://… |
| 连续 3 个以上空行 | 压成一个空行 |

## 5. 写入书里的规则

| 项 | 行为 |
|---|---|
| 从当前页覆盖 | 从光标所在页开始写入，**这一页及之后的内容会被删掉** |
| 末尾追加 | 接在最后一页后面，不影响已有内容 |
| 页数上限 | 整本 **100 页**（原版 `WritableBookContent.MAX_PAGES`），超出部分丢弃并在日志提示 |
| 单页字符上限 | 1024 字（原版编辑框上限），正常排版下根本用不到 |
| 空白页 | 不会写入；首尾空白会被 `strip()` |

导入前会弹确认框，写明"写入几页 / 从第几页开始覆盖 / 当前共几页"。

## 7. 常见问题

**导入后书里只显示了一半文字？**
说明分页没走显示宽度。检查配置里 `displayPaging=true`，且 `linesPerPage` 不超过 14。

**中文显示成方块？**
文件不是 UTF-8，或者用了游戏字体不支持的字符（生僻字、emoji）。换成 UTF-8 再导入；实在不行把那几个字换成常用字。

**页数比预期多很多？**
中文 170 字一页，10 万字就是 590 页，早就超过 100 页上限了。要么拆成多本书，要么减少 `---` 手动翻页。

**文件列表里看不到我的文件？**
检查扩展名是不是 `.txt` / `.md` / `.markdown`，以及是否放在了 `inkwell/` 的第一层。
